TSFix+ - installation
=====================

Smooth motion at your display's full refresh rate for Tales of Symphonia (Steam, PC), plus the
fixes the PC version still needs. Works on its own: TSFix, Special K and dgVoodoo aren't needed.
Works on Windows and on the Steam Deck.

Installing
----------
1. Open the game folder. In Steam, right-click Tales of Symphonia > Manage > Browse local files.
2. Copy d3d9.dll and tsfixplus.ini from this zip into that folder (next to TOS.exe).
   If Windows asks whether to replace an existing d3d9.dll, you have TSFix or Special K
   installed: see "Coming from TSFix" below.
3. Start the game. Press F9 at any time to turn the smoothing on and off.

A file called tsfixplus.log appears in the game folder when the game runs; it's useful if you
report a problem.

Recommended settings
--------------------
- Windows' refresh rate: Settings > System > Display > Advanced display > Choose a refresh rate:
  pick the highest. TSFix+ shows as many frames as the desktop refreshes.
- The game's resolution: your screen's own resolution (for example 3840x2160 on a 4K screen).
- HDR screens: turn Auto HDR off for TOS.exe (Settings > System > Display > Graphics).

Settings (tsfixplus.ini)
------------------------
MaxFPS=0        0 shows as many frames as your display refreshes. A lower number, such as 60
                or 90, uses less GPU power.
TexturePacks=1  Loads TSFix-format texture packs from TSFix_Res\inject, if you have any.
                0 turns them off.

Steam Deck
----------
In Desktop Mode, copy d3d9.dll and tsfixplus.ini into the game folder as above. That's all.
Leave the frame rate limit off in the quick menu; on a Steam Deck OLED, set 90 Hz for 90 fps.
(If the game stays at 30 and no tsfixplus.log appears, add this launch option in Steam:
right-click the game > Properties > General > Launch Options: WINEDLLOVERRIDES="d3d9=n,b" %command%)

Coming from TSFix (or TSFix+ 0.9)
---------------------------------
1. If TSFix made you use the game's 2016 launch version, restore the current one: Steam >
   right-click the game > Properties > Installed Files > Verify integrity of game files.
2. Delete from the game folder: d3d9.dll, d3d9.ini, tsfix.dll, tsfix.ini, dgVoodoo.dll and
   dgVoodoo.conf (if there), and TSFix+ 0.9's tsfixplus.dll, install.bat, uninstall.bat and
   tsfixplus-setup.ps1. Keep the TSFix_Res folder for its texture packs.
3. Install TSFix+ as above.

Uninstalling
------------
Delete d3d9.dll, tsfixplus.ini and tsfixplus.log from the game folder.

More information, and how to report a problem: https://github.com/coreyvanderlaan/ts-fix-plus
