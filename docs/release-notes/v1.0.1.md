Documentation update: **no changes to TSFix+ itself** (the same code as 1.0.0).

- **Steam Deck confirmed working**, at 90 fps on a Steam Deck OLED. Installing is the same as on Windows: copy `d3d9.dll` and `tsfixplus.ini` into the game folder. **No launch options are needed.** (If the game stays at 30 and no `tsfixplus.log` appears, the README has a one-line fallback.)
- `INSTALL.txt` in the zip is updated to match.

If you already have 1.0.0 installed, there's nothing you need to do.

**To install:** download `tsfixplus-1.0.1.zip` below (under Assets) and copy **`d3d9.dll`** and **`tsfixplus.ini`** into the game folder (in Steam: right-click Tales of Symphonia → Manage → Browse local files). See the [1.0.0 notes](https://github.com/coreyvanderlaan/ts-fix-plus/releases/tag/v1.0.0) for everything new in 1.0, and the [README](https://github.com/coreyvanderlaan/ts-fix-plus#readme) for recommended settings and coming from TSFix.
